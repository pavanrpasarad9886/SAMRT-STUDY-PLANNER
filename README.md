# SMART STUDY PLANNER

## 📚 About the Project

SMART STUDY PLANNER is a web-based study planning and progress tracking application designed to help students organize their studies effectively.

It helps students create study plans, manage tasks, and track their study progress in one place.

## 🎯 Problem Statement

Students often find it difficult to organize their study schedules, keep track of completed tasks, and maintain consistent study habits.

## 💡 Solution

SMART STUDY PLANNER provides a simple and user-friendly platform where students can:

- Create and manage study plans
- Track completed tasks
- Monitor study progress
- Organize their academic activities
- Stay consistent with their study goals

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- Local Storage

## ✨ Features

- Study planning
- Task management
- Progress tracking
- Simple and responsive interface
- Data stored using browser Local Storage
